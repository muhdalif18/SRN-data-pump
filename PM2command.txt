generate-pdf.js PM2 commands
=============================

Run once:
npm run generate-pdf:one

Start with PM2 (auto-restart forever):
npm run generate-pdf:forever

View logs:
npm run generate-pdf:logs

Stop:
npm run generate-pdf:stop

Raw PM2 equivalents:
pm2 start ecosystem.config.cjs --only generate-pdf-forever
pm2 logs generate-pdf-forever
pm2 delete generate-pdf-forever
