================================================================================
                    INDIVIDUAL SCRIPT COMMANDS
================================================================================

Each script has 4 commands:
  :one     - Run once (foreground, exits after completion)
  :forever - Start with PM2 (background, auto-restart on crash)
  :logs    - View PM2 logs for this script
  :stop    - Stop PM2 process for this script

================================================================================
                    CRASH RECOVERY COMMANDS
================================================================================

All scripts now have automatic crash recovery! If a script crashes, PM2 will
automatically restart it and it will continue from the last completed iteration.

# Check current progress for any script
cat test-data/progress-e2e.txt
cat test-data/progress-SRN-PUMP-LATEST.txt
cat test-data/progress-SRN-PUMP-LATEST-DIKECUALIAKN-MISSING-PHONE-STAFF-FEDS.txt

# Reset progress (start from iteration 1)
# Example for e2e:
npm run e2e:stop
del test-data\progress-e2e.txt
npm run e2e:forever

# Example for SRN-PUMP-LATEST-DIKECUALIAKN-MISSING-PHONE-STAFF-FEDS:
npm run srn-pump-latest-dikecualiakn-missing-phone-staff-feds:stop
del test-data\progress-SRN-PUMP-LATEST-DIKECUALIAKN-MISSING-PHONE-STAFF-FEDS.txt
npm run srn-pump-latest-dikecualiakn-missing-phone-staff-feds:forever

# Reset all progress files
del test-data\progress-*.txt
del test-data\srn-pump-*-progress.txt

# View permanent log (all runs)
cat test-data/srn-permanent-log.txt

                    TROUBLESHOOTING
================================================================================

# Process won't stop
pm2 delete <process-name>-forever
pm2 kill

# Check if PM2 daemon is running
pm2 ping

# Restart PM2 daemon
pm2 kill
pm2 resurrect

# Process keeps restarting
npm run <script-name>:logs
# Check for errors in the logs

# Clear everything and start fresh
npm run bots:stop-all
pm2 flush
npm run bots:all

================================================================================
                    NOTES
================================================================================

1. ALL scripts with loops now have automatic crash recovery
2. PM2 auto-restarts scripts after crash (10 second delay)
3. Scripts automatically resume from last completed iteration
4. Progress files are saved in test-data/ directory
5. Progress files are git-ignored
6. Multi-worker scripts use separate output directories:
   - worker1: test-results/
   - worker2: test-results-worker2/ (or variant-specific directories)
   - worker3: test-results-worker3-dikecualiakn/

7. Staggered start uses 60 second delay to prevent resource conflicts
