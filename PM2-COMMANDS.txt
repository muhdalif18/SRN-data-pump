================================================================================
GLOBAL PM2 MANAGEMENT COMMANDS
================================================================================
Start all bots:         npm run bots:all
Stop all bots:          npm run bots:stop-all
Check status:           npm run bots:status

Direct PM2 commands:
List all processes:     pm2 list
Monitor dashboard:      pm2 monit
Restart a process:      pm2 restart <name>
Delete a process:       pm2 delete <name>
Delete all processes:   pm2 delete all
Save PM2 config:        pm2 save
Resurrect saved:        pm2 resurrect
Flush logs:             pm2 flush
Show logs (all):        pm2 logs
Show logs (specific):   pm2 logs <name>

================================================================================
USEFUL TIPS
================================================================================
1. Always check status before starting: npm run bots:status
2. To stop a stuck process: pm2 delete <name> (not just stop)
3. Logs are stored in: %USERPROFILE%\.pm2\logs\
4. PM2 restart delay is 10 seconds for all processes
5. All processes have autorestart: true enabled
6. Use 'pm2 monit' for real-time monitoring with CPU/Memory stats

================================================================================
TROUBLESHOOTING
================================================================================
Process won't stop:
    pm2 delete <name> --force

Clear all PM2 data:
    pm2 kill

Check if PM2 daemon is running:
    pm2 ping

Restart PM2 daemon:
    pm2 kill
    pm2 resurrect

View detailed process info:
    pm2 show <name>
